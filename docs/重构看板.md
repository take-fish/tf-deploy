## 8. 本地构建注意

- **验证一律用 `mvn -B clean verify`**：`target/classes` 里残留的旧 `data.sql` 会被 Spring SQL init（`spring.sql.init.mode=always`）自动执行，把演示书灌进测试用 H2（`jdbc:h2:mem:fm_reader`），导致 `ReaderBookMapperTest` 期望 3 本、实际 4 本而误报失败。2026-10-28 在 tf-reader 上踩过一次：清理 target 后 50 个测试全绿，CI 不受影响。
- 各仓 `target/` 不纳入版本控制，切换分支后建议先 clean 再验证。
