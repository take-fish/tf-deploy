### 3.1 Lombok 统一

六个 Java 仓统一用 Lombok 消除手写构造器与 Logger，只引入 `@RequiredArgsConstructor` 与 `@Slf4j`，不引入 `@Data` / `@Getter` / `@Setter`（避免无意暴露可变状态）。

| 仓库 | `@RequiredArgsConstructor` | `@Slf4j` |
|---|---:|---:|
| tf-common | 5 | 3 |
| tf-user | 9 | 3 |
| tf-chat | 14 | 7 |
| tf-reader | 14 | 2 |
| tf-game | 39 | 11 |
| tf-music | 9 | 0 |

跳过构造器改造的情况：构造参数带 `@Value` 注入、存在多个构造器、构造体内含非赋值语句、字段声明顺序与构造参数顺序不一致。自定义 Logger 名（`com.fishmatrix.http.AccessLog`）保留手写，不用 `@Slf4j` 替换。

## 8. 本地构建注意

- **验证一律用 `mvn -B clean verify`**：`target/classes` 里残留的旧 `data.sql` 会被 Spring SQL init（`spring.sql.init.mode=always`）自动执行，把演示书灌进测试用 H2（`jdbc:h2:mem:fm_reader`），导致 `ReaderBookMapperTest` 期望 3 本、实际 4 本而误报失败。2026-10-28 在 tf-reader 上踩过一次：清理 target 后 50 个测试全绿，CI 不受影响。
- 各仓 `target/` 不纳入版本控制，切换分支后建议先 clean 再验证。
